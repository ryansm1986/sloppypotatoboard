# 🥔 Sloppy Potato Board

A good-looking soundboard for Windows that plays clips **through your mic** into games and Discord, with global hotkeys that work while you're in a fullscreen game.

- **Your voice + the board, one mic.** Your real microphone is passed through and mixed with the clips.
- **Auto-swap.** Your mic fades out the instant a clip plays and fades back in when it's done, so nobody hears a muddy mix. Switch to **Mix** if you want to talk over clips.
- **Global hotkeys** (Num 1–9 are pre-set, Num 0 stops everything, Num . mutes your mic).
- **Dead-simple importing:** drag files or links onto the window, paste a link with Ctrl+V, or drop files into the sounds folder.
- **Share boards:** right-click a board tab → *Share*. Friends double-click the `.potatopack` file to add it.
- **Quick filter:** just start typing anywhere to filter the buttons, use the arrow keys, and press Enter to play the highlighted one. Tag chips (Captain, Flight attendant, Lock-on, Radio…) narrow it down in one click. Esc clears.
- **Updates itself** from GitHub Releases: the installed version downloads updates in the background, and the portable exe swaps itself out on restart.
- Comes with an **Airplane** board: seatbelt chime, call-button bing-bong, a jet takeoff, and 34 pilot / flight-attendant announcements (including the classic "fasten seatbelt sign" one) written for gamers ("No Healer", "Lower Than Your Ping", "Lavatory Camper", "Captain Is AFK"…).
- A **Cockpit** board: a lock-on tone, missile-lock warning, Sidewinder growl-to-tone, "Pull up!", "Fox two!", and tower radio chatter.
- An **I Think You Should Leave** board with ready-made slots. Hit *Find it* on a slot, then drag the clip onto it.

## Installing (you and your friends)

Grab the latest from **[Releases](https://github.com/ryansm1986/sloppypotatoboard/releases/latest)** and send friends that link:

| File | What it is |
| --- | --- |
| `SloppyPotatoBoard-Setup-x.y.z.exe` | One-click installer. Adds Start menu + desktop shortcuts. Updates itself. |
| `SloppyPotatoBoard-Portable-x.y.z.exe` | Single exe, nothing to install. Also updates itself (swaps in the new exe on restart). |

The app isn't code-signed, so Windows SmartScreen may say *"Windows protected your PC"*. Click **More info → Run anyway**.

## First-time setup (about a minute)

The app walks you through this on first launch:

1. **Install the virtual mic.** One click. It downloads the free [VB-CABLE](https://vb-audio.com/Cable/) driver from VB-Audio and runs it. Windows asks for permission twice (Yes → Install). If the device doesn't show up after a bit, restart your PC.
2. **Pick your mic and headphones** and check the level meter.
3. **Connect it to your games**, either way works:
   - **Automatic (recommended):** the app makes itself your Windows default mic while it's running and switches back to your real mic when you quit. Works with any game or Discord set to the "Default" microphone.
   - **Manual:** in your game or Discord, set the microphone to **CABLE Output (VB-Audio Virtual Cable)**.

Use **Hear what games hear** (setup or Settings) to listen to exactly what your friends will hear.

## Tips

- **Type to filter.** No need to click the search box: start typing, arrows move the highlight, Enter plays it, Esc clears. `/` or Ctrl+F also jumps to search. Searching matches names, boards, tags, and hotkeys (try `num 3`).
- **Right-click** any sound to rename it, pick an emoji and color, set its volume, add tags, or record a hotkey.
- Hotkeys without Ctrl/Alt/Shift are limited to F-keys, numpad keys, Insert/Home/End/PgUp/PgDn, so you can still type.
- **Push-to-talk in game?** Clips only go through while you hold the key. Voice activation works best.
- If a game runs **as administrator**, Windows won't let normal apps' hotkeys reach it. Run the board as admin too.
- Closing the window keeps the app in the tray so hotkeys keep working. Quit from the tray icon.
- Your sounds live in `%APPDATA%\Sloppy Potato Board\sounds`. Anything you drop in there shows up automatically.

## Building from source

Needs Node 20+.

```bash
npm install
npm start          # build the UI and run the app
npm test           # quick test of the sound library logic
npm run dist       # build release/ installer + portable exe locally (no publishing)
```

### Shipping an update

1. Bump `version` in `package.json` (e.g. `1.1.0` → `1.2.0`) and commit.
2. Tag and push: `git tag v1.2.0 && git push origin main --tags`.
3. The **Release** GitHub Action builds both exes and publishes the release. Everyone's app finds it within a few hours (or right away via Settings → Updates → Check now).

New bundled sound packs go in `resources/packs/<id>/pack.json`. Existing users get any pack they haven't seen yet on their next update; packs they already have (or deleted) are never re-added.

### Regenerating the sound packs

The airplane and cockpit packs are generated by `tools/make_airplane_pack.py` and `tools/make_more_packs.py` (synthesized chimes and tones, Microsoft neural TTS via `edge-tts`, and cabin-PA / radio / cockpit effect chains):

```bash
python -m venv --system-site-packages tools/.venv
tools/.venv/Scripts/pip install edge-tts numpy scipy soundfile
npm run sounds
```

### How the audio works

The app runs two audio graphs. **Game**: your mic → high-pass → volume → auto-swap gate, mixed with clips → soft limiter → `CABLE Input`. Games listen to the other end, `CABLE Output`. **Monitor**: clips only → your headphones. The cable's own output is never offered as "your mic", so it can't feed back into itself. Until a cable is found the game mix goes nowhere, so you never hear yourself through your speakers.

Project layout: `electron/` (main process: library + bundled packs, hotkeys, Windows audio device switching, VB-CABLE installer, link import, updater), `src/` (Svelte UI, Web Audio engine in `src/lib/audio.js`, filtering in `src/lib/filter.svelte.js`), `resources/` (bundled packs + PowerShell helper), `tools/` (sound generators, icon renderer, tests).
